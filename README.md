# Podostemaceae-niche-modelling

Integrative niche modelling workflow for Neotropical Podostemaceae,combining occurrence records with climatic, topographic, hydrological, and soil landscape predictors.

## Citation
If you use the data, scripts, or workflow from this repository, please cite:

Bocanegra-González, K. T., Sparreo, L., & Bedoya, A. M. (2026)
*Environmental niche characterisation, overlap, and modelling in Neotropical riverscapes: a case study in strictly riverine plants (Podostemaceae).*
